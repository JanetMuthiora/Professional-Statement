Projects and Labs
1. Malware delivery & reverse-connection analysis (sandboxed - Kali Linux, Windows VM 8)
2. Threat attack simulation using a python script with a self replicating virus
3. File integrity verification and cryptographic protection of data in a Linux lab environment using hashing algorithms (MD5, SHA-256) and symmetric encryption (AES-256 with OpenSSL).
4. File Hashing, Integrity and Authentication using the following tools
   - Hashing (Integrity): MD5, SHA-256, and RIPEMD-160 produce a fixed-length fingerprint of a message. If the message changes, the hash changes.
   - HMAC-SHA-256 uses a secret key + the message. It proves the message hasn’t changed and that it came from someone who knows the key.
   - 3DES (DES3) encrypts the message into ciphertext so it can’t be read without the key. Your code also decrypts to show you can recover the original.
