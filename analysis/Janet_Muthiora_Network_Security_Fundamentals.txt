049: Alice is a CQUniversity student majoring in ICT. While studying the TLS key exchange process, she reviews a diagram that includes three key components:
050: the server's digital certificate,
051: the pre-master secret, and
052: the master secret and session keys.
053: However, she is confused about the roles of each component in establishing a secure connection, as well as the difference between symmetric and asymmetric cryptography. As her classmate and cybersecurity enthusiast, you are asked to help explain the process.
054: Purpose of the server’s digital certificate in the TLS key exchange process?
055: The server sends the digital certificate to prove the identity of the web server to the client, it contains the server’s public key signed by a trusted Certificate Authority. The client can verify the certificate by using the Certificate Authority’s  Public key to check that the digital signature matches the certificate data (Cloudflare Learning n.d.).
056: Key exchange process
057: The pre-master secret is an auto generated number by the client and is encrypted using the public key from the certificate and send to the server whereby only the server ca decrypt with its private key (Cloudflare Learning n.d.).
058: Master secret and session keys
059: Both Client and Server use the pre-master secret plus random values to form the master secret. Using the master secret the symmetric keys, that is the session keys are created an this will be used for encryption, integrity checks and facilitate secure data exchange (Cloudflare Learning n.d.).
